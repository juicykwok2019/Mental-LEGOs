# Scenario material routing

Classify each authorized item before analysis:

- Requirement: role description, agenda, request, success criteria.
- Personal evidence: confirmed experience, project record, metrics, portfolio.
- Counterparty context: public information or user-provided notes, with source and date.
- Constraint: time, confidentiality, non-negotiable boundary, decision authority.
- Prior interaction: questions, objections, commitments, unresolved items.

Keep source boundaries. A requirement is not evidence that the learner has satisfied it. A resume statement is a claim until linked to supporting experience. A probability estimate must show the signals that informed it.

Extract only the minimum material needed for the current scenario and retain stable references to the authorized copy.
