# Modular professional speaking structure

Build talks from retrievable units:

- Opening module: audience problem, credible tension, and promise.
- Orientation module: what will be covered and why the order matters.
- Point modules: one judgment, mechanism, evidence, and implication each.
- Transition modules: close the prior point and name the reason for the next.
- Closing module: return to the promise, state the decision/action, leave a retrieval phrase.
- Q&A modules: clarify, scope, bridge, evidence, limitation, and follow-up commitment.

Create 15-second, 45-second, and full variants by removing evidence depth, not by speeding speech. Test whether modules can be reordered when audience interest changes.
