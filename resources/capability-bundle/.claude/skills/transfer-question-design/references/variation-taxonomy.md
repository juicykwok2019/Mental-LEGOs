# Transfer variation taxonomy

- Audience: interviewer, customer, executive, peer, public audience.
- Objective: explain, decide, persuade, defend, summarize, redirect.
- Pressure: short notice, interruption, skepticism, missing information.
- Abstraction: principle, method, concrete incident, counterfactual.
- Evidence: metric, mechanism, example, tradeoff, limitation.
- Time: 15 seconds, 45 seconds, 2 minutes, long-form plus Q&A.
- Composition: one module, connector + viewpoint, viewpoint + evidence + close.

A valid transfer set changes the retrieval path, not merely synonyms. Avoid varying so many dimensions at once that failure cannot be diagnosed.
