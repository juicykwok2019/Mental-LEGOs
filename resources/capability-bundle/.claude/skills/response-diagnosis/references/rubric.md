# Spoken-response diagnostic rubric

Evaluate six independent dimensions:

1. Question convergence — did the response define which part of an open question it would answer?
2. Core judgment — is there a defensible central claim, decision, or position?
3. Logical structure — can a listener predict how supporting points relate?
4. Evidence — are facts, examples, mechanisms, or experience connected to the claim?
5. Closure — does the ending return to the question or practical implication?
6. Retrieval and language — where do latency, repetition, abandoned clauses, or generic wording indicate a recall/encoding bottleneck?

Use `observed`, `inferred`, or `unknown` for each conclusion. Prefer one high-leverage bottleneck over a long list. Compare attempts by changes in evidence and behavior, not by prose similarity.
