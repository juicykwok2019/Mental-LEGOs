# Profile assertion states

- `confirmed_fact`: explicitly confirmed by the learner and linked to evidence.
- `learner_viewpoint`: a position the learner recognizes as their own, with scope.
- `observation`: a repeated or notable behavior visible in authorized evidence.
- `hypothesis`: a possible explanation requiring further evidence.
- `conflicted`: credible evidence points in different directions.
- `retired`: no longer relied upon, retained only when provenance/audit requires it.

Every candidate needs a bounded subject, context, evidence references, confidence, and reviewability. Prefer “In architecture review questions, the learner tends to define constraints before recommending a path” over “The learner is analytical.”
